\## 📌 What is MimicDocs?



\*\*MimicDocs\*\* is a free, browser-based tool that converts your images into professional documents. Everything runs inside your browser — your images never leave your device. No server, no account, no watermark.



\---



\## ✨ Features



| Feature | Description |

|---|---|

| 🖼️ Image to PDF | Convert JPG, PNG, WEBP, BMP to PDF with A4 or fit-to-page layout |

| 📝 Image to Word | Convert images to editable .docx files |

| 📊 Image to PowerPoint | Each image becomes its own slide in .pptx format |

| 🗜️ Image Compressor | Compress images before converting to reduce file size |

| 💧 Watermark | Add custom watermark text to your output documents |

| 🔒 PDF Password | Protect your PDF output with a password |

| 📄 Merge PDFs | Combine multiple PDF files into one |

| 🌙 Dark / Light Mode | Toggle between dark and light theme |

| 📦 Batch Convert | Upload and convert up to 20 images at once |

| 🔐 100% Private | All processing happens in your browser — zero uploads |

| ⚡ Instant | No waiting, no server processing |

| 🆓 Free Forever | No account, no watermark, no hidden fees |

\## 🚀 How to Use



1\. Go to the live website

2\. Drag and drop your images or click \*\*Browse files\*\*

3\. Choose your output format — PDF, Word, or PowerPoint

4\. Set your options (quality, watermark, password, etc.)

5\. Click \*\*Convert with MimicDocs\*\*

6\. Click \*\*Download\*\* to save your file

\## 🛠️ How to Run Locally



\### Requirements

\- \[Node.js](https://nodejs.org) v18 or higher

\- \[Git](https://git-scm.com)



\### Steps



```bash

\# Clone the repository

git clone https://github.com/YOURUSERNAME/mimicdocs.git



\# Go into the folder

cd mimicdocs



\# Install serve

npm install -g serve



\# Run locally

serve .

```



Then open your browser and go to:

http://localhost:3000
